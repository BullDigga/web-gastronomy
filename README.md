Web Gastronomy — это современное веб-приложение для любителей кулинарии. Приложение позволяет пользователям находить, создавать, сохранять и делиться рецептами. Особенностью проекта являются уникальные встроенные инструменты, призванные сделать процесс готовки максимально комфортным и приятным.

Ключевые возможности:
  Для всех пользователей (Гостей)
    Просмотр рецептов: Доступ к публичной библиотеке рецептов с детальным описанием.
    Поиск и фильтрация: Удобный поиск рецептов по названию, ингредиентам, категориям.
    Система комментариев: Просмотр отзывов и обсуждений к любому рецепту.
  Для зарегистрированных пользователей
    Создание рецептов: Интуитивный интерфейс для добавления собственных рецептов с фотографиями, ингредиентами и пошаговыми инструкциями.
    Личный кабинет: Управление своими рецептами и избранным.
    Комментирование и оценка: Возможность оставлять комментарии и оценивать рецепты других пользователей.

Уникальные функциональные особенности
  Фиксированная панель ингредиентов:
    Список ингредиентов закреплен в левой части экрана и всегда доступен, куда бы пользователь ни прокрутил страницу рецепта. Не нужно постоянно возвращаться в начало, чтобы перепроверить ингредиенты.
    Встроенный кухонный таймер: Позволяет установить таймер прямо на странице рецепта. Больше не нужно переключаться между приложением и отдельными программами-таймерами.
    Встроенный радиопроигрыватель: Создайте идеальную атмосферу для готовки! В правой части экрана доступен плеер для проигрывания музыки или подкастов, который также закреплен и всегда под рукой.

Технологии и реализация
  Backend: Python + Django
  Frontend: HTML, CSS, JavaScript
  База данных: PostgreSQL
